# Quick Task 260504-004: Move E-Hentai Cookie Fields Into Settings - Context

**Gathered:** 2026-05-04
**Status:** Ready for planning

<domain>
## Task Boundary

Move E-Hentai cookie recording out of the Search pane and into Settings, using the EhViewer-style individual cookie fields `ipb_member_id`, `ipb_pass_hash`, and `igneous`.

</domain>

<decisions>
## Implementation Decisions

### Cookie Shape
- Store three named fields instead of a pasted full Cookie header.
- Compose the Cookie header only at request time.

### UI Location
- Place cookie fields in the Settings dialog.
- Keep favorites URL, target folder, limit, auto-check, and manual import in the Search pane.

### Security
- Do not write real cookie values into planning artifacts or logs.
- Continue using config persistence for this quick task; OS keychain encryption remains future work.

</decisions>

<specifics>
## Specific Ideas

- Use password inputs for `ipb_pass_hash` and `igneous`.
- Keep `ipb_member_id` as normal text because it is usually an id-like value.

</specifics>
