# Quick Task 260504-002: Add E-Hentai Favorites Import Download Flow - Context

**Gathered:** 2026-05-04
**Status:** Ready for planning

<domain>
## Task Boundary

Add support for automatically searching and downloading comics from an E-Hentai user's favorites using a standard pasted cookie login flow and a user-selected download folder.

</domain>

<decisions>
## Implementation Decisions

### Authentication
- Use pasted cookie text only. Do not store cookies in config and do not ask for account password.

### Import Scope
- Start with a single E-Hentai or ExHentai favorites page URL and parse gallery links from that page.
- Queue matching Hitomi comics by gallery id.

### Download Folder
- Let the user choose a target folder for this import run.
- Keep the existing configured directory format under that selected base folder.

### Agent Discretion
- Use a conservative MVP rather than browser cookie extraction or multi-page crawling.
- Surface found, queued, and failed counts after import.

</decisions>

<specifics>
## Specific Ideas

- Add controls in the Search pane because the flow starts from remote discovery and creates normal download tasks.
- Reuse the existing download manager so imported items appear in the existing downloads UI.

</specifics>
