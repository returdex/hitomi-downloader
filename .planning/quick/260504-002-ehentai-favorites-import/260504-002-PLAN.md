# Quick Task 260504-002: Add E-Hentai Favorites Import Download Flow

## Description

Allow users to paste an E-Hentai cookie, provide a favorites URL, choose a target folder, and queue matching favorites as normal download tasks.

## Tasks

1. Backend import command
   - Add `import_ehentai_favorites`.
   - Parse E-Hentai gallery ids from favorites HTML.
   - Queue matching comics with an import-specific base download folder.

2. Frontend controls
   - Add compact controls to the Search pane for cookie, favorites URL, target folder, optional limit, and import action.
   - Show a completion notification with found, queued, and failed counts.

3. Verification
   - Run Rust checks and frontend build.
   - Record warnings and residual limitations.
