# Quick Task 260504-003: Persist E-Hentai Cookie and Auto-Check Favorites

## Description

Save E-Hentai favorites import settings so the app can check for new favorites when it starts.

## Tasks

1. Persist settings
   - Add config fields for cookie, favorites URL, selected download folder, limit, auto-check, and known gallery ids.

2. Avoid duplicate imports
   - Extend the import command to accept known ids and skip them during update checks.
   - Return found ids so the frontend can update config after each successful check.

3. Startup check
   - On app startup, if enabled and configured, check the saved favorites page and queue only new items.

4. Verification
   - Run Rust and frontend build checks.
