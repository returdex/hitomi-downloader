<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| component -> generated Tauri command | A user-selected page number crosses an asynchronous command boundary. |
| test fixture -> component/store | Synthetic results enter the real Pinia state; fixtures must contain no cookies, filesystem paths, or user configuration. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | `handlePageChange` state publication | mitigate | Publish `currentPage` and `store.searchResult` only after the generated command returns success. |
| T-02-02 | Information disclosure | `SearchPane.spec.ts` fixtures/output | mitigate | Use synthetic IDs/results and never import or print runtime config, cookies, or paths. |
| T-02-03 | Denial of service | test command | accept | The focused one-shot local test has bounded fixtures and no network/service dependency. |
</threat_model>
